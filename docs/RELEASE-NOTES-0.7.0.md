# Xmouse 0.7.0

## S 手势兼容性

修复 Codex、Chromium 和 Electron 类界面中“C 可以复制，但 S 提示没有读取到选中文本”的时序问题。UI Automation 无法提供选区时，Xmouse 会临时发送 `Ctrl+C`，最长等待 1.5 秒，直到剪贴板完成更新且 Unicode 文本真正可读；随后恢复原剪贴板。

临时复制与恢复期间继续暂停历史捕获。失败信息现在保留具体阶段，便于从日志区分“没有选区”“复制未更新”和“剪贴板已更新但文本仍不可读”。

## 个性化手势

- 侧边栏新增“个性化手势”页。
- 可分别选择 ↑、L、S、C、V，并在画布中按自己的习惯用左键绘制。
- 每个动作最多保存 3 份样本；第 4 份会替换该动作最早的样本。
- 样本原子写入 `%LOCALAPPDATA%\Xmouse\config.json`，保存后立即影响最终识别和按住触发键时的实时预测。
- 个人模板与内置模板共同匹配；清除当前动作的个人样本后自动恢复为纯内置识别。
- 轨迹仍使用 64 点重采样、平移/尺度归一化、余弦匹配、最低置信度与候选分差保护，不会因为添加个人样本而绕过拒绝机制。

## 工程结构

个性化画布的命中区域和绘制移入 `ui/gesture_editor.rs`，手势样本结构、归一化和识别留在 `gesture.rs`，配置校验留在 `config.rs`，窗口过程只负责消息协调与持久化连接。

## 验证

- Release 单元测试覆盖个人模板学习、旧配置兼容、每动作样本上限及原有手势/剪贴板功能。

- 使用隔离配置完成浅色、深色个性化手势页和实际左键轨迹保存验收。
