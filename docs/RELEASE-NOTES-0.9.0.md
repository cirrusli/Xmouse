# Xmouse 0.9.0

发布日期：2026-07-26

## 新增功能

- 按住触发键向左画横线：切换到左侧虚拟桌面。
- 按住触发键向右画横线：切换到右侧虚拟桌面。
- 两个动作使用 Windows 原生快捷键 `Win+Ctrl+←/→`，无需管理员权限。
- 个性化手势页新增“← 左桌面”和“→ 右桌面”，每个动作可学习最多 3 份个人轨迹。
- 绘制过程中，屏幕底部的预测提示会提前显示将要切换的方向。

## 使用提示

1. Windows 需要至少创建两个虚拟桌面；可按 `Win+Tab` 创建和管理桌面。
2. 切换桌面时画一条方向明确的水平线，建议长度至少 60 DIP。
3. 如果个人绘制习惯有弧度，可在“个性化手势”页分别录制左右轨迹。
