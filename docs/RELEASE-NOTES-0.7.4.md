# Xmouse 0.7.4

## 剪贴板历史点击修复

0.7.3 同时实现了点击窗口外关闭和点击弹窗内部空白背景关闭。内部背景关闭的命中范围过大，会让用户在搜索框、列表和操作区之间点击时误关窗口。

0.7.4 移除内部点击关闭，只保留顶层窗口失活关闭：

- 点击搜索框、历史列表、按钮或弹窗背景时保持打开。
- 点击其他窗口或切换至其他应用时自动关闭。
- 外部关闭不会抢回焦点。
- `Esc`、复制完成和右上角关闭按钮继续正常工作。
- 删除、清空确认框仍视为历史窗口的拥有窗口，不会触发自动关闭。

## 验证

- `cargo check`、Release 测试、`cargo build --release` 和 Clippy `-D warnings` 通过。
- Win32 消息冒烟测试覆盖弹窗根区域、搜索框、历史列表和外部失活路径。
