# Xmouse 0.12.0

发布日期：2026-07-27

## 手势与动作正式解耦

- 识别器只判断你画的是 ↑、L、S、C、V、← 或 →，再由配置决定最终动作。
- 在“个性化手势”页选择一条轨迹，点击“执行”即可修改绑定；实时预测会显示“轨迹 → 动作”。
- 每条轨迹仍可学习最多 3 份个人样本。个人样本属于轨迹形状，修改动作不会删除或重新训练样本。
- 可以把不需要的轨迹设为“不执行动作”。

## 固定安全动作白名单

- 剪贴板与搜索：搜索选中文本、复制、打开历史、粘贴。
- 窗口：置顶/取消置顶、关闭标签页、最小化、最大化/还原。
- 浏览器：后退、前进。
- 桌面：切换左/右虚拟桌面、显示桌面、任务视图。
- 媒体与音量：静音、降低/提高音量、播放/暂停。

Xmouse 不开放任意脚本、命令行、插件或网络动作。涉及目标窗口的动作仍先验证并激活按下触发键瞬间锁定的窗口；激活失败时安全终止。

## 配置兼容与工程拆分

- 旧版 `custom_gestures[].action` 会按原默认含义迁移为新的轨迹 ID。
- 旧配置没有 `gesture_bindings` 时自动使用原默认动作，不改变现有使用习惯。
- 新增 `action.rs` 作为动作领域模型；手势页控件和布局迁移到 `ui/gesture_settings.rs`，继续缩小主设置模块职责。
