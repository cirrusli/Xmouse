# Xmouse 0.14.2

修复左右划线手势显示“已切换桌面”却没有实际切换的问题，并防止模拟右键反复进入手势识别。

原因是当前键盘映射在本机把左右方向键转换为没有 `E0` 前缀的扫描码。Xmouse 之前只根据该前缀设置扩展键标志，结果发出的并非 Windows 虚拟桌面快捷键所需的独立方向键。现在方向键始终设置 `KEYEVENTF_EXTENDEDKEY`。

本机用两个虚拟桌面验证：旧序列 `SendInput` 返回 6/6，但桌面未变化；修正序列实际切换到左侧，并成功切回原桌面。新增回归测试检查按键序列和扩展键标志。

鼠标钩子现在放行系统标记为注入的鼠标输入，避免 Xmouse 重放右键时再次创建候选手势。曾用模拟右键复现连续重放与日志快速增长；修正后相同模拟单击不再产生重放循环，进程保持运行。由于模拟事件现在按设计不触发手势，完整左右手势需要使用实体鼠标验收。
