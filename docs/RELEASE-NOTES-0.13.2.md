# Xmouse 0.13.2

发布日期：2026-08-24

## 手势稳定性

- Xmouse 现在监听 Windows 前台窗口切换事件，并在切换应用时重新安装全局低级鼠标钩子。
- 如果钩子曾被 Windows 静默移除，或任务管理器等高权限窗口临时隔离了普通权限钩子，切回 ChatGPT、Edge、资源管理器等普通应用后会自动恢复。
- 恢复机制由 WinEvent 触发，不增加后台轮询、心跳鼠标事件或定时器。
- 钩子回调不再等待设置配置锁；遇到极短暂竞争时优先保留原始鼠标输入。

## 系统右键保护

- 任务栏及第二显示器任务栏不再启动手势候选，右键应用图标会立即显示 Windows 原生菜单。
- 托盘溢出区、任务栏缩略图、Win32 系统菜单和 XAML 系统弹窗同样受到保护。
- 资源管理器窗口、普通应用以及桌面画布仍可正常使用手势。

## 仍然存在的 Windows 边界

普通权限 Xmouse 无法在任务管理器或其他管理员窗口本身上处理手势，这是 UIPI 的系统安全限制；本版修复的是离开这些窗口后的自动恢复。
