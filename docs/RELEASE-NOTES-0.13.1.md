# Xmouse 0.13.1

发布日期：2026-07-29

## 圆形手势容错

- 圆形闭合门槛由单一最大跨度比例改为横纵轴分别归一化后的距离，横向或纵向椭圆、DPI 缩放和绘制比例不再改变闭合判断。
- 闭合距离上限从 40% 调整到 55%，可以接受约六分之一圈的自然重叠。
- 圆形相似度使用独立门槛，在全局识别阈值基础上放宽 0.04；↑、L、S、C、V、左右划和 7 不受影响。
- 64 点轨迹出现非相邻线段交点且端点距离仍接近闭合时，圆形候选额外获得 0.05 分；交点是高权重证据，但不会绕过模板相似度和候选分差。
- 用户在“个性化手势”中为圆形录制的最多 3 份样本仍会优先参与匹配，过画样本不会再被旧闭合门槛提前过滤。

## 防止误识别

- 闭合距离按横纵轴分别归一化，避免被拉伸的 C 因宽高比变化而落入圆形候选。
- 自动测试逐份验证所有内置模板，而不只是每种手势的第一份模板。
- 新增顺时针、逆时针、横纵椭圆、适度过画、个性化过画圆和远端交叉开放轨迹反例测试，并继续验证 C、L、V 与 7 的区分。
- 39 项常规 Release 测试与 1 项真实剪贴板往返测试通过；格式检查、Release 构建和 Clippy 严格检查通过。
