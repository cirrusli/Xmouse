# Xmouse 0.14.0

## 应用保护

- 设置侧边栏新增“应用保护”页。
- 先切换到目标应用，再从托盘打开 Xmouse 设置，即可把该应用的 EXE 加入手势禁用名单。
- 命中名单后 Xmouse 完全放行右键或侧键，不创建手势候选，也不显示轨迹。
- 禁用名单支持大小写无关去重、按项移除，并保存在 `gesture_guard.excluded_processes`。
- 原有“所有全屏窗口暂停手势”保留并移入该页面；关闭它后可只保护指定游戏。

## 无畏契约登录器说明

本机现场检查显示，中国大陆版无畏契约登录器的两个 `1152 × 720` 小窗口和此前的全屏页面都属于同一个受保护进程。小窗口不再符合 Xmouse 的全屏暂停条件；手动启动的 Xmouse 仍是中等完整性，启用管理员开机启动后则以最高可用权限运行。即使提权，受保护进程仍可能隔离输入，这属于 Windows UIPI/进程保护边界，不是轨迹识别失败。

应用保护名单解决的是“在实际游戏里完全放行鼠标”，不会绕过 Windows 权限隔离；管理员启动也不能突破反作弊保护和安全桌面。

## 管理员开机启动

- 常规页的开机启动已升级为当前用户登录时以最高权限运行。
- 首次启用会显示一次 Windows UAC；创建成功后，后续登录不会重复确认。
- 实现使用 Windows 计划任务，不修改程序清单，因此手动双击 Xmouse 仍保持普通权限且不会每次弹 UAC。
- 关闭开关会删除计划任务；升级时会清理旧版 `HKCU Run` 启动项。
- 计划任务仅绑定当前用户，允许在电池供电时启动和持续运行，并忽略重复实例。
- 管理员运行可改善普通高完整性窗口兼容性，但不会绕过反作弊保护进程或 UAC 安全桌面。
