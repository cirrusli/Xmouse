# Xmouse 0.13.3

发布日期：2026-08-24

## L 手势与键盘框架兼容

- `Ctrl+W`、`Ctrl+C`、`Ctrl+V` 等键盘动作改用 Windows 硬件扫描码，不再只提交虚拟键值。
- 键盘事件不再携带鼠标钩子使用的自定义 `dwExtraInfo` 标记；鼠标重放的防递归逻辑保持不变。
- `Ctrl` 组合键现在模拟实体按键时序：先按修饰键，再按普通键，保持短暂按压后按相反顺序释放。
- 若事件发送中途失败，Xmouse 会尽力补发普通键和 Ctrl 的释放事件，避免修饰键停留在按下状态。

这修复了 FlClash 等 Flutter 桌面应用中“提示已发送 Ctrl+W，但窗口没有处理”的问题。L 手势仍然只发送 `Ctrl+W`，不会降级为 `Alt+F4` 或直接关闭窗口。
