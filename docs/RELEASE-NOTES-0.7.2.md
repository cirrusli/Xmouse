# Xmouse 0.7.2

## S 手势剪贴板恢复

0.7.1 保存的是 `OleGetClipboard` 返回的活动 `IDataObject`。它可以读取当时的剪贴板，但不是冻结的数据副本；目标程序响应临时 `Ctrl+C` 后，再把该对象交给 `OleSetClipboard`，对象会在 OLE 已持有剪贴板锁时尝试重新打开剪贴板，最终持续返回 `0x800401D0 (CLIPBRD_E_CANT_OPEN)`。

0.7.2 在发送临时 `Ctrl+C` 前枚举剪贴板格式，并把每个 `HGLOBAL` 格式复制成 Xmouse 自己拥有的字节数据。搜索文本读取完成后，程序直接清空临时内容并逐格式写回，不再依赖已经失效的系统剪贴板对象。

- 保留 Unicode 文本、HTML、来源 URL/token 等自定义内存格式。
- 图片剪贴板存在 DIB/DIBV5 数据时，可以省略等价的 GDI 位图/调色板句柄。
- 对其余无法可靠备份的特殊句柄格式，S 手势会在发送 `Ctrl+C` 前取消，避免损坏原内容。
- 单次快照上限为 128 MiB；恢复占用重试窗口延长到约 3.8 秒。
- 临时复制与恢复期间继续暂停历史捕获，不会把中间内容写入历史。

## 验证

- 22 项常规单元测试通过。
- 额外真实剪贴板往返测试通过，覆盖 Unicode 文本、HTML、自定义格式、临时替换与逐格式恢复。
- `cargo check`、Release 测试与 Clippy `-D warnings` 通过。
