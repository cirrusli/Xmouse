# Xmouse 0.7.3

## 轨迹层

此前轨迹点已经会在手势结束和下一次开始时清空，但 Win32 分层窗口由 DWM 保留的合成表面仍可能是上一帧。隐藏窗口上的同步 `WM_PAINT` 并不足以保证新表面已经交给合成器，因此下一次显示时可能短暂出现上一条轨迹。

0.7.3 对显示过程增加透明门控：

1. 轨迹层保持全透明并重新显示。
2. 使用本次轨迹重绘完整虚拟桌面表面。
3. 等待 DWM 提交重绘结果。
4. 最后恢复不透明度。

结束手势时执行相反流程，在透明状态下把合成表面同步清成空白后再隐藏。

## 剪贴板历史关闭方式

- 点击剪贴板历史窗口外或切换至其他程序时自动关闭。
- 点击弹窗内容区域的空白位置也会关闭。
- 点击外部关闭时保留用户刚刚点击的窗口焦点，不再强制跳回打开历史前的窗口。
- `Esc`、右上角关闭按钮和复制完成后仍会恢复原窗口。
- 删除、清空确认框属于历史窗，不会被失焦逻辑误关。

## 验证

- `cargo check`、Release 测试和 Clippy `-D warnings` 通过。
- 通过 Win32 消息冒烟测试验证历史窗在失活和内容空白点击时隐藏，并可再次正常打开。
