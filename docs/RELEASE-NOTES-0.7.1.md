# Xmouse 0.7.1

## 轨迹显示与实时预测

此前 Xmouse 会从按下触发键开始记录完整轨迹，但覆盖层要等激活延时和位移同时满足后才显示。0.7.0 在显示覆盖层时只发送了起点，下一帧才发送当前点，因此前半段在视觉上被错误连接成一条直线，松手前预测也没有使用完整的前半段。

0.7.1 在激活瞬间一次性发送已经缓存的全部点，然后继续增量发送新点。覆盖层重新显示前会先用新状态同步重绘，避免显存中的上一条彩色轨迹短暂出现。

## S 手势

- `OleGetClipboard`、`OleSetClipboard` 和 `OleFlushClipboard` 增加退避重试，应对 Codex、Chromium、Electron 或其他程序短暂占用剪贴板。
- UI Automation 无法读取选区时仍发送临时 `Ctrl+C`，最长等待 1.5 秒，读取完成后恢复原 OLE 数据对象。
- 完整错误链写入日志；提示不再只显示笼统的“临时复制选中文本失败”，而会指出保存、复制、读取或恢复的具体阶段。
- 临时忽略计数在操作结束时统一清理，不会因为复制或恢复少产生一次事件而漏记下一次正常复制。

## 个性化手势

修复个人轨迹经过尺度归一化后范围约为 1，却再次被原始像素尺寸规则拒绝的问题。归一化样本现在只拒绝真正退化或非有限的轨迹，可以正常保存并热更新识别器。

## 验证

- 21 项 Release 单元测试通过。
- `cargo check` 与 Clippy `-D warnings` 通过。
- 新增完整激活前轨迹传递和归一化样本二次校验测试。
