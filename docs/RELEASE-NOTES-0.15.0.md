# Xmouse 0.15.0

## 手势使用统计

设置侧边栏新增“手势统计”。选择“今日”“本月”或“今年”，可查看绘制次数、已识别次数、动作提交成功次数、未完成绘制次数，以及九种轨迹按使用频率排序的排行。页面可见时有新手势会自动刷新；隐藏时不做定时查询。

每次明显拖动并松开触发键后，`%LOCALAPPDATA%\Xmouse\xmouse.log` 写入一条摘要：轨迹类型、绑定动作、结果、置信度和采样点数量。相同事件写入独立的 `gesture-stats.db`，用于日/月/年聚合。长度不足的明确拖动标记为 `too_short`；普通右键单击不计入统计。不保存轨迹坐标、目标应用、选中文本或剪贴板正文。“成功”指 Xmouse 动作调用返回成功，桌面边界、目标应用是否响应等外部效果仍需实机确认。

日志达到 512 KiB 时会在运行中轮转，保留上一份 `xmouse.log.1`。

## 桌面切换回归来源

通过 Git 历史定位到 `20a658d`（2026-08-24）：为兼容 Flutter/FlClash，把键盘事件从虚拟键码改为扫描码；此后左右方向键在本机未获得扩展键标志，`SendInput` 虽然报告发送成功，Windows 却没有切换桌面。0.14.2 已补齐 `KEYEVENTF_EXTENDEDKEY`，本版继续保留该回归测试。
