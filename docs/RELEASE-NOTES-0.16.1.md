# Xmouse 0.16.1

修复 Edge 普通大窗口被误判为全屏、导致手势完全不触发的问题。

旧逻辑只排除系统“最大化”状态，再按窗口是否覆盖屏幕判断全屏；手动拉大的普通窗口、恢复后的近屏幕尺寸窗口仍可能命中。现在增加原生标题栏样式判断，普通有框窗口不会因覆盖屏幕被暂停；无需加入 Edge 白名单或关闭游戏全屏保护。

无边框全屏游戏沿用原覆盖判定和越界容差，进程禁用名单仍独立生效。该保护仍是窗口样式/几何启发式，不承诺识别所有特殊渲染或受保护游戏。

应用保护页将目标改称“最近活跃应用”，明确显示空禁用名单；空名单时“移除应用”不可点击。

回归覆盖现场 Edge 样式/尺寸、有框窗口精确覆盖/越界，以及无边框游戏在负坐标、多种分辨率、边框样式下的保护判定。按用户要求不再继续 computer-use 或实体手势复现；自动化通过不等同于所有游戏/浏览器已实机验收。
