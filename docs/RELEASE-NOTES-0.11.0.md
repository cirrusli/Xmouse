# Xmouse 0.11.0

发布日期：2026-07-27

## 更快定位剪贴板内容

- 历史弹窗新增“全部 / 文本 / 图片”分段筛选。
- “所有应用”菜单按最近使用顺序列出来源程序，可与类型和搜索词同时组合。
- 搜索命中的内容或来源应用名称会直接高亮；中文和英文大小写搜索均可用。
- 类型和来源会在文本解密、缩略图解码前过滤，筛选不会额外读取无关内容。

## 对齐 Windows 剪贴板体验

- “选择后自动粘贴”默认开启，也可在剪贴板设置页关闭。
- 通过 V 手势或托盘直接打开历史时，按 Enter、双击或点击“复制”会把内容写入剪贴板、关闭弹窗、恢复原窗口并发送 `Ctrl+V`。
- 如果目标窗口已经关闭或 Windows 阻止激活，内容仍保留在剪贴板，只提示自动粘贴失败，不会把输入发送到其他窗口。
- 从设置页打开历史时没有外部目标窗口，因此继续执行“只复制”，避免误操作设置界面。

## 验证

- 深色模式下的类型按钮、来源按钮、搜索框、列表和操作区视觉检查通过，文字与筛选行没有截断。
- 类型/来源/搜索组合过滤及来源聚合自动测试通过。
- 中文与 ASCII 大小写高亮范围自动测试通过。
- 28 项常规自动化测试通过；1 项会改写真实剪贴板的测试按需运行。
- Release 构建、格式检查和 Clippy 严格检查通过。
