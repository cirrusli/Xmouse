# Xmouse 0.13.0

发布日期：2026-07-29

## 两个新手势

- `7` 默认打开任务管理器，对应系统快捷键 `Ctrl+Shift+Esc`。
- `○` 默认打开 Windows 截图选择层，对应系统快捷键 `Win+Shift+S`。Xmouse 不显示置顶提示，避免提示条出现在截图中。
- 圆形模板覆盖多个起点、顺时针/逆时针和横纵椭圆，并允许末端轻微未闭合；如果个人画法差异较大，仍可在“个性化手势”页为圆形录制最多 3 份个人样本。

## 桌面切换方向

- 左划现在切换到右侧虚拟桌面，右划切换到左侧虚拟桌面，行为类似用手拖动桌面画布。
- 配置 schema 从 1 升级到 2。仅当左右轨迹仍保持旧版默认映射时自动对调；已经自行改绑的动作保持不变。

## 深色剪贴板修复

- “全部 / 文本 / 图片”切换改为不擦除背景的同步自绘重绘，不再短暂闪出白色。
- 来源应用菜单在深色模式下自绘背景、悬停状态、文字和勾选标记；浅色模式仍使用系统原生菜单。
- 菜单保持原生 `HMENU`、键盘导航和命令返回方式，不引入新的 UI 运行时或后台线程。

## 验证

- 36 项常规 Release 自动化测试通过，覆盖新轨迹识别、闭合度区分、配置迁移和自定义映射保留。
- 1 项真实剪贴板往返测试已单独运行并通过；Release 构建、格式检查与 Clippy 严格检查通过。
- 深色历史弹窗的分段按钮和来源应用菜单完成实际界面回归。
- 50.36 秒托盘空闲测量中 CPU 增量为 0，平均私有内存 2.285 MiB，平均工作集 14.069 MiB。
