# Xmouse 0.10.0

发布日期：2026-07-27

## 游戏与全屏保护

- 常规页新增“全屏应用中暂停手势”，默认开启。
- 当前台目标窗口覆盖整个显示器时，Xmouse 会在触发键按下前直接放行事件，不显示轨迹、提示或菜单重放，也不会发送任何模拟输入。
- 普通最大化窗口会被排除在全屏判定之外，浏览器和桌面工作流仍可正常使用手势。
- 该规则覆盖独占全屏和大多数无边框全屏场景，适合 Valorant、GTA5 等游戏；窗口化游戏后续可加入独立的手势应用排除列表。

## 钩子性能优化

- 没有候选手势时，普通鼠标移动直接通过原子状态检查返回，不读取配置，也不进入互斥锁。
- 仅在触发键按下时读取一次配置；延时、距离阈值和目标窗口随后保存在候选状态中。
- 手势排除规则与剪贴板记录排除规则已经解耦，为后续按应用行为留出独立配置边界。

这次改动主要降低高轮询率鼠标持续移动时的钩子开销。空闲状态原本已经是消息驱动，因此空闲 CPU 的绝对变化预计很小；收益主要出现在游戏和持续移动鼠标的场景。

## 验证

- 全屏、容差边缘、工作区最大化和普通窗口的矩形判定测试通过。
- 旧配置可自动补齐全屏保护默认值，剪贴板排除项不会再影响手势。
- 26 项常规自动化测试通过；1 项会改写真实剪贴板的测试按需运行。
- Release 构建、格式检查和 Clippy 严格检查通过。
- 关闭测试工具的 UI Automation 附加后，Release 版纯后台稳定采样 45.56 秒：CPU 未产生可测增量，私有内存平均 `8.78 MiB`，工作集平均 `28.65 MiB`，满足既定空闲资源目标。
