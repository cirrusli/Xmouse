# Xmouse 0.14.0

## 应用保护

- 设置侧边栏新增“应用保护”页。
- 先切换到目标应用，再从托盘打开 Xmouse 设置，即可把该应用的 EXE 加入手势禁用名单。
- 命中名单后 Xmouse 完全放行右键或侧键，不创建手势候选，也不显示轨迹。
- 禁用名单支持大小写无关去重、按项移除，并保存在 `gesture_guard.excluded_processes`。
- 原有“所有全屏窗口暂停手势”保留并移入该页面；关闭它后可只保护指定游戏。

## 无畏契约登录器说明

本机现场检查显示，中国大陆版无畏契约登录器的两个 `1152 × 720` 小窗口和此前的全屏页面都属于同一个受保护进程。小窗口不再符合 Xmouse 的全屏暂停条件，但 Xmouse 默认以中等完整性运行，仍可能无法在受保护或高完整性窗口中稳定接收和注入输入。这属于 Windows UIPI/进程保护边界，不是轨迹识别失败。

应用保护名单解决的是“在实际游戏里完全放行鼠标”，不会绕过 Windows 权限隔离。Xmouse 不会自动申请管理员权限。
