# Xmouse 0.5.0

## 剪贴板置顶

- 在历史弹窗选中记录后，可以使用“置顶”或“取消置顶”。
- 置顶记录始终排在普通记录之前，多个置顶项按最近置顶时间排序。
- 重复复制同一内容会更新来源和使用时间，但不会丢失置顶状态。
- 普通容量淘汰不会自动删除置顶记录；如果置顶内容本身超过容量上限，Xmouse 会保留置顶内容，并优先淘汰普通记录。
- 删除单条置顶记录会二次确认；“清空历史”仍会删除全部内容，但在包含置顶项时会给出明确提示。

## UI 工程化

UI 继续使用轻量的原生 Win32/GDI 实现，但已经从 `app.rs` 拆分为独立职责：

- `ui/theme.rs`：浅色/深色配色、字体和 DWM 主题。
- `ui/native.rs`：原生控件创建、字体应用和圆角区域。
- `ui/widgets.rs`：按钮、开关、分段选择和卡片绘制。
- `ui/settings.rs`：设置页布局及控件集合。
- `ui/history_popup.rs`：历史弹窗布局和控件 ID。
- `ui/history_view.rs`：历史行、图片缩略图和置顶标记渲染。
- `ui/format.rs`：容量、时间和运行时长格式化。

`app.rs` 只保留窗口过程、状态协调与业务命令连接。与 0.4.0 相比，它减少约 1,000 行，并且绘制模块不再直接读写全局应用状态。

## 数据兼容

首次运行会自动把历史数据库升级到 schema 版本 2，已有记录默认不置顶，不需要手工迁移。升级会新增 `pinned` 和 `pinned_at` 字段及排序索引；原有文本、图片、明文和 DPAPI 内容格式保持不变。

## 验证

- 14 项 Release 单元测试全部通过。
- Clippy 以 `-D warnings` 运行通过。
- 深色和浅色历史弹窗均完成截图检查；置顶、取消置顶、计数和按钮状态完成 UI 冒烟验证。

Release 版启用手势和剪贴板监听后后台空闲 60.90 秒实测：CPU 约 `0.0225%`，私有内存平均 `2.16 MiB`、峰值 `2.20 MiB`，工作集平均 `14.41 MiB`、峰值 `14.43 MiB`，稳定后 4 个线程、155 个句柄。这些数据是当前机器的空闲实测，不代表图片转换或打开大量历史时的瞬时峰值。
