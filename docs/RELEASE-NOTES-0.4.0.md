# Xmouse 0.4.0

## 本版变化

- 设置页改为简洁的圆角卡片布局，传统复选框和下拉框替换为自绘开关与分段按钮。
- 新增深色模式，并与剪贴板历史弹窗同步；标题、搜索框和列表均使用同一套主题配色。
- 常规页只保留启用手势、开机启动、深色模式与触发键，高级识别参数继续保留在配置文件中。
- 新增“资源占用”页，按需显示 CPU、GPU、私有内存、工作集、句柄数和运行时间。
- 剪贴板历史页及弹窗右上角显示记录总数和实际磁盘占用。
- 修复左上角品牌副标题以及历史标题、列表文字截断。
- 右键轨迹新增最短长度校验，默认 28 DIP；短按和短距离抖动按普通单击处理，不再显示“手势太快”。
- 操作提示固定在鼠标所在显示器的底部居中位置。
- 开机启动仍使用当前用户的 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，无需管理员权限；已启用时会自动修复可执行文件路径。

## 界面实现

可见控件继续采用 Win32/GDI，但按钮、开关、导航和分段选择均由 Xmouse 自绘，并启用 Common Controls v6、DWM 深色标题栏及 Per-Monitor V2 DPI。这样可以直接获得统一的简约圆角视觉，同时保持原生窗口、托盘、全局鼠标钩子和剪贴板消息架构。

资源采样只在“资源占用”页打开时按每秒一次更新；其他页面及后台状态不会因此新增轮询。GPU 显示为 `0% / GDI 软件绘制`，表示 Xmouse 没有创建独立 GPU 渲染设备。

最终 Release 版启用手势（X2 触发）与剪贴板监听后后台空闲 60.86 秒实测：

- CPU 时间增量低于本次 Windows 进程计时分辨率，折算显示为 `0%`。
- 私有内存平均 `2.15 MiB`，峰值 `2.19 MiB`。
- 工作集平均 `14.48 MiB`，峰值 `14.50 MiB`。
- 稳定后 4 个线程、155 个句柄。

这些数据是当前机器的空闲实测，不代表图片转换或打开大量历史记录时的瞬时峰值。

## 配置兼容

旧配置会自动补入：

```json
{
  "dark_mode": false,
  "minimum_stroke_length_dip": 28.0
}
```

默认搜索引擎保持 Google，剪贴板新记录默认明文保存；“本机加密”只影响启用后的新记录，旧记录仍可兼容读取。
