# Xmouse 0.6.0

## 图片悬停预览

历史弹窗中的图片记录继续显示 48px 缩略图。鼠标停留在图片所在行时，Xmouse 会在历史窗口旁显示最长边不超过 360px 的大图预览；鼠标移开、开始搜索或关闭历史窗口后，预览自动消失。

原图读取、DPAPI 解密和缩放在独立后台线程执行。鼠标消息和 UI 线程只负责请求与绘制，不会在悬停回调中同步读取大文件。透明图片会与棋盘背景合成，避免原生 GDI 忽略 Alpha 后显示黑块。

## 删除保护

- 删除普通单条记录前会确认。
- 清空全部历史前会确认，并明确提示无法撤销。
- 置顶记录不能直接删除；单条删除会提示先取消置顶。
- 只要历史中仍有置顶记录，就不能执行“清空历史”。
- 保护同时位于 UI 和 SQLite 存储接口，后续新增入口也不能绕过。

## 实时手势预测

进入手势模式后，Xmouse 会在当前显示器底部持续显示预测状态。轨迹尚不明确时显示“正在识别手势…”，达到与最终识别相同的置信度和候选分差后，显示对应动作，例如：

- `预计：↑ · 置顶窗口`
- `预计：L · 关闭页面`
- `预计：S · 搜索选中内容`

预测期间不会执行动作，只有松开当前配置的触发键（右键、X1 或 X2）后才会执行最终识别结果。

## 视觉修复

品牌名称、副标题和版本号不再使用容易残留系统底色的 `STATIC` 子控件，而是由主窗口与侧边栏一次性绘制。保存按钮也纳入主题刷新列表，修复深色冷启动和主题切换后的白色矩形、白边。
