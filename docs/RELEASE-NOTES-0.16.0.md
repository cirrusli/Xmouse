# Xmouse 0.16.0

本轮跟进外部评审的交付、UI 基础与扩展性三项问题。

## 已实现

- 单 EXE：SQLite 3.54.1 静态链接，无需附带 `sqlite3.dll`；`--self-test` 在用户数据、UI 和钩子初始化之前自检。CI 和本地使用相同默认特性。
- 键盘基础：设置/历史支持 Tab、Shift+Tab、Space、Enter、Esc，焦点框在深浅色可见，隐藏页跳过；分段选择使用方向键。历史搜索框的 Delete 只编辑搜索文本。
- 可访问性基础：原生 checkbox/radio 角色和状态、历史搜索/列表名称、统计数值摘要与可聚焦的真实排行列表；保留自绘外观，无额外 UI 框架。
- 应用关闭规则：从目标应用切换到设置 → 应用保护 → L 关闭规则，可选自动兼容、Ctrl+W、关闭当前窗口，保存后生效；自动兼容可撤销覆盖。Steam/Wallpaper UI 兼容集中到独立模块，普通应用不变。
- 标准关闭不是强杀进程：由目标应用决定关闭、询问保存或收回托盘。Steam 原本不响应 Ctrl+W，因此默认通过 `WM_CLOSE` 请求关闭当前窗口。

## 验证与边界

- 本地 Windows GNU Release：格式、Clippy、66 项常规测试通过；1 项真实剪贴板交互测试仍默认忽略。
- PE 导入不含 SQLite 或编译器外部运行时；只复制 EXE 到独立中文/空格目录，SQLite 3.54.1 读写和完整性自检通过。
- 隔离数据实例实测 Tab/Shift+Tab、方向键、空格、深浅色焦点外观；UIA 可读出 checkbox/radio 角色与名称。历史深色弹窗外观已抽查。
- 完整 Narrator、所有历史键盘路径、多 DPI、实体鼠标及跨应用兼容仍需人工回归；本轮不宣称完整无障碍支持，也未用调用成功冒充目标应用实际响应。
- 自定义组合键、配置导入/导出、动作结果分层与完整窗口控制器拆分列入下一轮；不包含任意脚本/插件。

历史版本归档在 `archive`，最新版本仍从根目录 `启动 Xmouse.cmd` 启动；用户数据与个人轨迹不变。
